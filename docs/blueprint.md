# **App Name**: Janvani HQ

## Core Features:

- User Authentication: Secure login system with role-based access control (Super Admin, Department Head, Operator) using email/password and Google OAuth. Includes multi-factor authentication option and session management.
- Real-time Issue Tracking: Dashboard displaying real-time metrics such as Total Reports, Resolved Issues, and Pending Approvals with week-over-week comparison.
- AI-Powered Issue Prioritization: Automatically set issue priority based on Green/Red flag thresholds. Includes manual review option.
- Department Management: Dedicated department dashboards displaying key metrics like Total Assigned issues, Completed issues, In Progress issues, Overdue issues, and Efficiency.
- Geospatial Visualization: Display issues on a map as a heatmap of civic issue reports.
- Issue Assignment: Assign the right issues to the right department by presenting the human user with a small number of choices generated by a tool that intelligently weighs multiple data points from an issue report.
- Real-time notifications: Get alerted via the Firebase cloud messaging whenever any change happens in any issue.

## Style Guidelines:

- Primary color: Deep blue (#1E40AF) for trust and government association.
- Background color: Light gray (#F8FAFC) for a clean, professional look.
- Accent color: Teal (#0A817B) for call to actions and interactive elements, providing a sense of success and resolution. (#059669 is already green).
- Headline font: 'Space Grotesk' sans-serif for headlines; its techy style emphasizes government modernity; pair with 'Inter' sans-serif for body text.
- Use consistent, professional icons from a standard library (e.g., Material Icons) to represent different categories and actions.
- Responsive layout with a clear visual hierarchy, ensuring important metrics stand out and are easily accessible on tablets and desktops.
- Subtle transitions and animations to provide feedback on interactions and guide the user through workflows.
